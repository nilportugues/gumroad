## What to run before merging the pushed branches

The baseline above is already red, so judge each branch by what it adds, not by a zero count.

1. `cd nextjs && node scripts/typecheck.ts`: must print at most the 2 existing own errors (`purchase-paid-order.golden.test.ts:206`, `stripe-account-deauthorized.ts:56`) and 105 shared errors. Any other line is new.
2. `npm run typecheck` at the root: must stay at 0.
3. `cd nextjs && npm run lint:baseline`: compare against this document, not against `lint-baseline.json` (stale). Expect untyped totals around 7574; ignore `worker/jobs/index.ts` `import/order` and `registry.generated.ts` `prettier` drift when several jobs branches merge, and fix those two once at the end (`eslint --fix src/worker/jobs/index.ts` and re-run the registry generator with formatting).
4. Type-aware lint (`npx eslint <changed files>`, not the whole tree) on the files each branch touches: new `require-await` and `no-unsafe-*` errors in non-test files are the ones worth blocking on.
5. `cd nextjs && npx vitest run`: the 22 failing suites above are the baseline. Run the six `replaceAll`/`quoteName` suites again after the subscriptions fix; anything else failing is new. Run the directory of the branch's own tests if the full 135 s run is too slow.
6. Regenerate the lint baseline (`npm run lint:baseline -- --write` equivalent in `scripts/lint-baseline.ts`) only after the final merge, so it does not conflict between branches.

Files that need attention first: `nextjs/src/server/models/subscription.ts` (import-time `star()` failure breaking 6 suites), `nextjs/src/server/models/stripe-account-deauthorized.ts` and `purchase-paid-order.golden.test.ts` (typecheck), `nextjs/src/worker/jobs/index.ts` and `nextjs/src/server/jobs/registry.generated.ts` (lint drift, fix last), and the stale mocks in `controllers/mobile-purchases.test.ts`, `settings-passkeys-mutations.test.ts` and the five `quoteName` suites.
